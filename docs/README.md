## 1. 游戏概览

- **类型**：轻量 Roguelike 弹幕射击（bullet-hell），单局 12–35 分钟。
- **平台**：桌面浏览器 + 移动浏览器（**仅横屏**）+ PWA 离线，打开即玩。
- **操作**：玩家光标 = 本体，自动开火；桌面 **WASD 移动 + 鼠标瞄准**，移动端 **横屏左摇杆移动 + 右摇杆瞄准**；「自动锁定最近目标」为可选设置，默认关闭。
- **辅助瞄准**：默认手动；开启后仅当手动瞄准空闲 0.4 s 时软锁 480 px 内最近敌人，手动输入立即覆盖（防“抢手”）。
- **局内**：磁盘 C:–G:，每盘 5 个文件夹关 + 1 个根目录 Boss；每关三选一增益（普通/稀有/传奇 = 6:3:1），Boss 必掉传奇。
- **生命**：RAM 5 格；归零蓝屏结算；通关显示“计算机已安全关机”。
- **局外**：碎片抽键帽，装入 87 键键盘，属性/套装永久成长。
- **美术**：桌面隐喻 + **真实软件图标**（Iconify `logos`/`simple-icons`/`devicon`，CC0/MIT/Apache-2.0）+ 等宽字符子弹。
- **技术**：Canvas 2D + TypeScript + 自研轻量 ECS + Web Audio 纯合成，运行时零第三方依赖、零网络请求。

### 核心循环

```
碎片 → 抽键帽 → 装键盘 → 变强
  ▲                          │
  └── 结算 ◄── 蓝屏/关机 ◄── 一局：C:→G:，每盘 5 文件夹 + Boss
```

## 3. Canon 速查（详细见 `00 §7`）

| 项 | 值 |
| --- | --- |
| 玩家 RAM / 攻击 / 攻击间隔 | 5 / 10 / 0.8 s（面板 1.25 发/s） |
| 操作 | 桌面 WASD 移动 320 px/s + 鼠标瞄准；移动端仅横屏双摇杆；自动开火；autoLock 默认关 |
| 普通小怪（节能 C） | HP 30 / 伤害 1 / 攻击间隔 0.8 s / 移速 60 |
| 缩放 | `K = 1 + 0.32(d−1) + 0.08(d−1)²`；`D = 1.00 / 1.30 / 1.60`；`M = K×D` |
| 磁盘数 | 节能 C–E（3）/ 平衡 C–F（4）/ 高性能 C–G（5） |
| 每盘结构 | 5 文件夹（每关 3 波：3 / 5 / 4+1 精英）+ 1 Boss |
| 增益 | 30 个：普通 12 / 稀有 10 / 传奇 8；三选一权重 6:3:1 |
| 键帽 | 87 键：普通 60 / 稀有 24 / 传奇 3；抽取 200 / 十连 1800 |
| 碎片 | `raw×D×(1+0.05×无伤关)×1.25`；节能满通关 ≈ 863 |
| 性能预算 | 首屏 ≤ 500 KB、全量 ≤ 1.6 MB、60 FPS、同屏 30 敌 / 240 敌弹 |
| 固定文案 | 蓝屏 `DESKTOP_WAR_RAM_EXHAUSTED`；通关“计算机已安全关机” |
| 语言 | `zh-CN` 默认；`en-US` 预留；文案键化 `src/i18n`，固定文案 token 不翻译 |

## 4. 文档治理

- `00-设计总纲.md` 是 **SSOT（唯一事实来源）**；任何子文档与它冲突，以 00 为准。
- 数值改动必须走 `00 §0.3` 变更流程（ADR + 同步子文档 + 调参记录）。
- 子文档引用 Canon 时写 `00 §7.3`，不复制整表。
- 未定项用 `【待定】` 标注并登记在对应文档的“待定项”表，不允许沉默留白。
- 图标许可：仅 CC0-1.0 / MIT / Apache-2.0；开源非商业声明与署名见 `00 §10.5` / `40 §4.2`。
- 设计→实现对照见 `60 §12`；每个里程碑结束做一次差异审计。

## 5. 项目结构（规划）

```
DesktopWar/
├─ docs/                  # 本设计稿（SSOT）
├─ tools/
│  ├─ balance_model.py    # 设计期平衡模型
│  ├─ keycap_table.py     # 87 键属性表校验
│  ├─ check_docs.py       # 设计稿一致性检查
│  └─ icons/*.ts          # Iconify 抓取/光栅化/图集/license（M1 落地）
├─ assets/icons/          # 图标原始缓存、图集、license 报告（M1 落地）
├─ src/
│  ├─ core/  ecs/  game/  render/  input/  audio/  ui/  data/  meta/
│  └─ main.ts
├─ public/                # manifest、Service Worker 静态资源
└─ package.json           # dev/build/test/icons:fetch/balance:check
```

> 当前仓库处于 **M0 设计阶段**：只有 `docs/` 与设计期校验脚本，尚无运行时代码。
