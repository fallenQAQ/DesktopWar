## 2. 快速开始

```bash
npm install
npm run dev        # http://127.0.0.1:5173

npm run build      # 产出 dist/
python tools/check_docs.py   # 设计文档一致性
```

## 5. 文档治理

- **SSOT**：`00` 是唯一事实来源；子文档与它冲突时以 00 为准。
- **数值变更**：走 `00 §0.3` 的 ADR 流程 → 同步 `src/data/` 与相关子文档 → 跑 `python tools/check_docs.py` 与 `tools/balance_model.py`。
- **引用而非复制**：子文档引用 Canon 时写 `00 §7.3`，不复制大段数值表；派生表只在 `50` 出现一次。
- **未决项**：统一用 `【待定】` 或 `TBD-*` 登记，并写明默认值与关闭条件；不允许沉默留白。
- **实现状态**：设计稿中的“计划/目标”不得写成既成事实；当前实现以本文 §1 与 `60 §1` 为准。
- **许可**：仅 CC0-1.0 / MIT / Apache-2.0 图标集；当前构建未打包第三方图标，声明见根 `README.md` 与 `public/licenses/`。
