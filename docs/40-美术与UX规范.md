## 1. 视觉概念与情绪板

**关键词**：极简桌面 · 图标磁贴 · 等宽字符 · 系统蓝 · CRT 微光 · 离线可信。**视觉陈述**：一块深色、干净、略过曝的旧电脑桌面；敌人是熟悉的软件图标，台词是命令行字符，死亡与胜利走系统级演出（蓝屏 / 关机）。

**三条不可让渡原则**：① 战场比 UI 亮（HUD 最高亮度 ≤ 磁贴高光）；② 3 层信息（常驻 / 事件 / 演出，同屏最多 2 层浮层）；③ 系统感来自排版与文案，不来自拟物（禁伪 3D、禁纹理堆叠）。

## 3. 布局、缩放与响应式

> Canon 引用：00 §3（统一 1280×720 横屏）、00 §9（DPR ≤ 2）、00 §12 TBD-01（仅横屏）、ADR-009。

| 项 | 桌面横屏 | 手机横屏 |
| --- | --- | --- |
| 世界逻辑分辨率 | 1280 × 720 | 1280 × 720（安全区 letterbox） |
| 安全边距 | 24（四边） | 上 56 / 下 48 / 侧 24，与 `env(safe-area-inset-*)` 取大（30 §5.2） |
| 栅格 | 12 列 / gutter 24 / margin 48 | 12 列 / gutter 16 / margin 12 |
| 最小触控目标 | 32（鼠标可 24） | **44 × 44 CSS px** |
| 正文基线 | `--dw-fs-body:16` | `--dw-fs-body:17` |
| 暂停入口 | `Esc` + HUD 右上按钮 | 右上 48×48（拇指可达） |
| 增益栏 | HUD 右下横向图标条 | 战场右下角上滑，4 列 × 2 行（瞄准摇杆上方） |
| 结算/窗口 | 居中 720×520 窗口 | 近全屏抽屉（左右 16，顶部 64） |

```txt
scale = min(vw/1280, vh/720)    // 桌面与移动横屏：contain，禁止 cover 裁掉判定点
canvas.backingStore = logical × min(DPR,2)
```

- 高度 ≤520 CSS px 时页面头部压缩：标题 18px、统计 10px、返回按钮 36px，避免键盘页头部换行挤压内容区。
- **contain 而非 cover**：宁可有黑边也不裁切；黑边用 `--dw-bg` + 1px 内侧 `--dw-border` 描边（模拟显示器边框）；手机横屏的 letterbox 也遵守，不拉伸战场。
- 高度不足允许 `scale < 1`，HUD 文字 < 11 CSS px 时提示「请放大窗口」；浏览器缩放 125–200% 以 CSS px 重排不裁切；**不提供竖屏布局**：竖屏（含运行中旋转）显示旋转覆盖层 + 自动 `pause.system`，旋转回横屏后保持暂停、由玩家继续（不重置局，§12）。
- 超宽屏：世界居中，两侧各 48px 渐隐、**不解锁视野**（保持 16:9 判定）；安全区与边界细节见 §12。

## 4. 图标规范（Iconify，计划）

> Canon 引用：00 §8（建议前缀）、00 §9（构建期抓取、图集化、运行时零网络）、ADR-005。
> **当前状态**：未接入 Iconify；`src/render/renderer.ts` 以软件名首字母/简称绘制磁贴，等同于 §4.5 L3。以下为接入时的目标规范。

### 4.1 prefix 分工（计划）

| prefix | 定位 | 使用范围 | 禁止 |
| --- | --- | --- | --- |
| `mdi` | **默认通用图标**（UI + 缺图回退） | 设置/文件夹/盾牌/云/时钟/终端；敌人/Boss 无品牌图标时的通用回退 | 品牌 logo 场合 |
| `carbon` | 线性技术图标（1.5px 线性、几何规整） | `engineering`/`security` 装饰与 HUD 小图标；缺图回退 | 需品牌识别处 |
| `devicon` | 真实开发工具/语言品牌（原色，MIT） | `code` 风格敌人与装饰 | 其他风格、非开发语义 |
| `logos` | 真实软件品牌原色 logo（CC0） | 全部风格的敌人/Boss/装饰优先；`life`/`office`/`network`/`creative` 原色识别 | UI 控件图标；暗示官方合作 |
| `simple-icons` | 真实软件品牌**单色回退**（CC0） | `logos` 缺失时的敌人/Boss 品牌图标；可按风格色 tint | 需多色辨识处 |
| 禁止 | emoji、`twemoji`、`noto`、自绘近似 logo | — | 全项目 |

> **敌人/Boss 优先真实软件图标**；`mdi`/`carbon` 仅作 UI 与缺图回退。**不要假设某品牌图标一定存在**：`assets/icons/manifest.ts` 每条必须写 `fallback` 链（§4.5）；抓取脚本遇缺失直接构建失败，禁止“运行时才发现没图”。

## 5. 玩家光标、准星、字符弹与战斗特效

> Canon 引用：00 §10.2（玩家光标 + 准星分离、箭头+拖尾、判定 3px、子弹 2–6 等宽字符、受击闪白/碎裂、动效 80–200 ms、屏震可关）、ADR-011。

### 5.1 光标（`cursor`）与准星（`reticle`）

**玩家光标**（WASD/方向键、左摇杆移动；唯一判定点）：经典箭头 24×32（移动 ×1.2），`#F8FAFC` 填充 + `#0B1220` 2px 外描边；热点 = 箭头尖端，**判定点半径 3**（00 §7.1），视觉不放大；320 px/s（WASD 8 向 / 左摇杆全向），拖尾 3 段 8/16/24 px、透明度 .35/.20/.10、70 ms；静止 ≥1.5 s 1 Hz 呼吸（减少动态关闭）；受伤 1.0 s 内 2 Hz opacity 1.0↔.35 + danger 外圈（§5.3）；左侧 12px 增益角标（`×3`、`»`）。

**瞄准准星**（鼠标位置 / 右摇杆；独立于光标、**不参与受击判定**，ADR-011）：十字（4 段 8px 线、中心空 6px）+ 外圆环 1px，总径 **24–28 逻辑 px**（桌面 24 / 移动 28），颜色 `--dw-accent` + `#0B1220` 1px 外描边；桌面跟鼠标坐标，移动跟右摇杆方向；鼠标静止但玩家移动时，准星位置不变、射击方向按相对位置实时更新；命中 80 ms 放大 1.15 + 白闪，auto-lock 锁定 120 ms 亮 4 段刻度（§9.3）。

**移动端双摇杆**（仅横屏；左移动 / 右瞄准，§6.5、§12）：浮动盘，左半屏 / 右半屏按下位置生成、松手 200 ms 淡出；底座 **96**、摇杆头 **44**、死区 **8**（逻辑 px）、整体 opacity **.35**（按下 .55）；底座 1px 虚线 `--dw-border` + 8% panel 填充，摇杆头 `--dw-panel-raised` + 1px accent 环；默认落点靠近左下/右下角、中心距角 ≥96 + `safe-inset`，不压 HUD 与增益栏；左摇杆方向 → 320 px/s（全向），右摇杆推杆即瞄准。

**流程边界**：① 抽取/结算过程中刷新页面 → 以存档为准（局内进度不落盘，30 §12），回 Hub 并 toast「上次运行已结束」；② 连点主按钮 → 首次点击后按钮 loading 且忽略 300 ms 内后续点击；③ 移动端系统返回键 → 子页逐级返回，运行中先弹暂停（防误退出）；④ 难度解锁与结算写入同一事务，避免「已解锁但未入库」。

### 8.4 语气规则

- **系统口吻**（Win9x/XP 时代）：陈述句，不用「请」「您」，不用感叹号；梗只放在可恢复/可失败处（错误、空状态、按钮副标签），不放在固定文案里。
- **术语统一**：RAM / 磁盘 / 键帽 / 碎片 / 增益 / 种子；禁用「血量」「抽卡」「皮肤」「角色」。
- **长度**：按钮 ≤6 汉字、Toast ≤18 汉字、空状态正文 ≤40 汉字；确认框标题用名词句（「放弃本次运行？」），禁止反问与第二人称祈使。
- **格式**：等宽阿拉伯数字、千分位逗号（1,240）、时间 `mm:ss`、种子 `0x` + 8 位大写十六进制、百分比取整。

### 8.5 本地化约束（预留）

- 源语言为 `zh-CN`；所有界面/内容文案走 `src/i18n` 的 `MessageKey`，本节中文仅为源文案，不得在 `src/ui`/`src/game` 硬编码。
- 固定文案可翻译：`:(`、`DESKTOP_WAR_RAM_EXHAUSTED`、`desktopwar.exe`、百分比与段落结构必须保留；译文按目标语言重排，不逐字直译。
- 布局按源文案预留 1.4× 宽度；按钮最多 2 行、Toast 可换行；动态路径可省略，固定文案不得截断。
- 字体：ASCII 用打包像素字体，CJK 用系统栈；`<html lang>` 随 `settings.language` 更新，`aria-label` 与可见文案同源。
- 数字/时间不本地化：`1,240`、`mm:ss`、24h `HH:mm`、`0x` + 8 位大写；v1 固定 `dir="ltr"`。

### 9.4 性能与减少动态

- 只动 transform/opacity/颜色；禁 width/height/top/left；同屏并发 ≤2 组；动画不阻塞输入；L2 降级关闭扫描线/粒子/HUD 呼吸（30 §15.3）。
- **减少动态**（默认跟随 `prefers-reduced-motion`）：屏震/拖尾/扫描线→关；卡牌→淡入；数字→直接显示；蓝屏→直接 100% 后 1.2 s 进结算；关机→一次显示；键帽飞行→直接落位。
- 流程由动画 `finish` 驱动、`setTimeout` 仅兜底；HUD 数值 ≤10 Hz（30 §15.2）。

### 10.3 混音与优先级

- 层级：`master .8 → compressor`；`music .55`、`sfx .8`；蓝屏/关机/结算音乐 400 ms 淡出（不做 ducking）。
- 声部 ≤16（00 §10.4），UI 4 专用槽；满时抢占「进度 >70% 且 gain 低」；`playerHurt`/`bsod`/`shutdown` 不参与；声像 ±0.2，移动端单声道兼容。

### 10.4 静音、解锁与移动端恢复

- 首次手势解锁（30 §7.2），未解锁全静默（Boot 提示告知）；音乐/音效独立 0–1（30 §12），0 = gain 0 不断开总线。
- 暂停/后台 `suspend()`；`visibilitychange` 隐藏 >1 s 后 suspend，恢复 resume 并丢弃过期音符（30 §8.3）。
- iOS 来电/中断：`ctx.state === 'interrupted'` 时 toast「声音已暂停 · 点击恢复」，点击 resume；不阻塞游戏（30 R5）；dist 音频文件数 = 0（CI）。
