### 4.1 兼容性测试流程

**矩阵**（2026-10-26 实测）：
- Edge/Chromium：1920×1080、1366×768、1440×900@2x、1024×768、2560×1080、1180×820@2x（触屏）、932×430@3x、844×390@3x、667×375@2x、568×320@2x、390×844（竖屏）。
- Firefox：1366×768、844×390；WebKit：1366×768、844×390；PWA 离线：1366×768；抽卡页：1366×768、844×390。

**步骤**：
1. `npm run build` → `npm run preview -- --host 127.0.0.1 --port 4173`。
2. 每个环境执行 Boot → Hub → 键盘 → 图鉴 → 设置 → 难度 → 运行 ≥5s；抽卡页额外验证；竖屏额外验证旋转提示，PWA 等待 SW ready 后断网刷新。
3. 检查：页面无横向/纵向溢出；canvas 与 HUD 在视口内；87 键 / 10 抽卡 / 设置窗口可达；单棋盘单详情；控制台 0 error。
4. 布局、CSS、输入或 PWA 变更后重跑全矩阵。

**通过标准**：上述检查全通过；竖屏仅显示旋转提示；断网刷新仍可到 Boot/Hub；无未归类错误。

**最近结果**：18 次运行全通过；修复 `/favicon.ico` 404 与 568×320 页面头部换行。**未覆盖**：真机双摇杆手势、iOS/Android 实机、PWA 安装图标。

## 7. 定义完成（DoD）

一个功能只有同时满足以下条件才算完成：

1. 行为符合对应设计稿，设计稿无未决冲突。
2. 有自动化测试或明确的手工验收步骤。
3. 桌面与移动端均验证（涉及 UI/输入时）。
4. 不突破体积/性能预算。
5. 文案、稀有度颜色、图标无占位（当前图标占位是已知例外）。
6. 存档兼容（涉及持久化时）。
7. 更新受影响的文档章节或 ADR，并保持版本号一致。
