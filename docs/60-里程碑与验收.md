## 3. M1 · 技术骨架

### 范围
- 工程：Vite + TS strict + pnpm；目录结构按 `30`；ESLint/Biome + Vitest。
- 核心：固定步长循环、轻量 ECS、对象池、种子 RNG、事件总线。
- 渲染：Canvas 分层、DPR、单一逻辑分辨率 1280×720 横屏、占位图形。
- 输入：WASD/方向键移动 + 鼠标瞄准（桌面）；横屏双虚拟摇杆（移动）；自动开火；`Esc` 暂停；竖屏旋转提示。
- 设置：`autoLock` 默认关闭；开启后仅在手动瞄准空闲 0.4 s 时软锁 480 px 内最近敌人。
- 音频：AudioContext 懒解锁、总线、一个测试音效。
- 资产管线：Iconify 抓取脚本跑通（先取 10 个图标），图集生成 + license 报告。
- CI：typecheck、test、build、体积门禁。

### 验收
- [ ] 桌面：WASD 可移动玩家光标，鼠标只改变准星/射击方向；自动开火正常。
- [ ] 移动端横屏：左右摇杆分别移动/瞄准；竖屏显示旋转提示并暂停；autoLock 默认关闭。
- [ ] 同种子两次运行，实体状态哈希一致（确定性测试）。
- [ ] 首屏传输 ≤ 500 KB，JS gzip ≤ 180 KB。
- [ ] `pnpm icons:fetch` 在无缓存目录可复现产物；断网后运行时零请求。
- [ ] 失焦/切后台自动暂停，恢复不跳帧。

### 风险
- ECS 过度设计：实体上限 1024、组件 ≤ 16，超过即评审。
- 双分辨率适配复杂：先用统一世界坐标 + 安全区，不做两套逻辑。

## 4. M2 · 核心战斗

### 范围
- 玩家：自动开火、0.8 s 间隔、10 伤害、900 弹速、3 px 判定、1 s 无敌；WASD/左摇杆移动 + 鼠标/右摇杆瞄准。
- 瞄准：默认手动瞄准；`autoLock` 作为设置项接入（空闲 0.4 s、480 px、360°/s 软锁）。
- 字符弹：字形图集渲染、命中/消散特效、对象池。
- 敌人：6 原型行为与 4 类弹幕、精英、生成/退场、空间哈希碰撞。
- 波次：3/5/4+1、数量公式、同屏上限、清场判定。
- RAM：扣血、+1 回复、死亡、复活类增益钩子。
- 结算：蓝屏页（固定文案）→ 简易结算。
- Boss：C 盘「系统更新」完整两阶段。
- 平衡校验：公式单测 + TTK 仿真。

### 验收
- [ ] 可完整游玩“节能 C 盘：5 文件夹 + Boss”，全程无阻塞 bug。
- [ ] 单文件夹 35–55 s；C 盘 Boss 45–75 s（按 70% 输出窗口）。
- [ ] 240 发敌弹 + 30 敌同屏 ≥ 55 FPS，无 GC 卡顿尖峰。
- [ ] 伤害/死亡/复活顺序符合 `10 §10`；蓝屏文案逐字一致。
- [ ] 公式单测覆盖 `00 §7.3` 全部 15 格缩放表。

### 风险
- 移动端手感：横屏双摇杆的底座/行程/死区需真机调参；auto-lock 默认关，避免抢手。
- 子弹视觉与判定不一致：判定必须小于视觉，且可在设置中显示判定点。

## 5. M3 · 完整关卡循环

### 范围
- 磁盘 C–G、5 文件夹、风格不重复抽取、层间过场。
- 30 个增益全量接入、6:3:1 权重、Boss 传奇三选一、重随。
- 8 个 Boss（每风格 1 个）机制与阶段。
- 结算页：统计、碎片公式、通关/失败两种画面。
- 种子系统、暂停（任务管理器）、放弃本局、切后台恢复。

### 验收
- [ ] 节能 3 磁盘全通，时长 12–16 min。
- [ ] 平衡 4 磁盘、高性能 5 磁盘可通，时长落在 18–24 / 25–35 min（允许 ±20%）。
- [ ] 30 增益全部可获取、可叠层、满层正确排除；无死锁组合。
- [ ] 8 Boss 均可击杀，无卡阶段/无敌锁死。
- [ ] 同种子重放关键随机序列一致。
- [ ] 经济：节能满通关碎片落在 750–950。

### 风险
- 内容量：8 Boss × 3 弹幕模式是最大工作量，优先做 C/F/G，其余复用骨架换皮。
- 风格抽签：一局内不重复，池耗尽时按规则回填（见 `10`）。

## 6. M4 · 局外成长

## 7. M5 · 美术 / UX / 音频

### 范围
- 8 风格图集（每风格 6 敌人 + Boss + 装饰），核心 UI 图标，全部构建期内联。
- 全部界面按 `40` 落地：Boot、Hub、难度、HUD、增益窗口、Boss 条、暂停、BSOD、Shutdown、结算、键盘、抽取、图鉴、设置。
- 动效：受击、击杀、卡牌、蓝屏进度、关机、键盘弹起。
- 音频：合成音效全量、2 轨程序化音乐、总线/静音/移动端解锁。
- 无障碍：减少动态、震动开关、判定点显示、色盲纹理、键盘可操作。

### 验收
- [ ] 所有界面在 1280×720、844×390（手机横屏）、超宽屏、刘海屏下无遮挡/溢出；竖屏仅旋转覆盖层。
- [ ] 蓝屏/关机/更新窗口文案与 `00 §10.3` 逐字一致。
- [ ] 首屏 ≤ 500 KB；全量 ≤ 1.6 MB；单风格图集 ≤ 80 KB。
- [ ] 无音频文件；首次手势后 100 ms 内可出声；静音状态持久化。
- [ ] `prefers-reduced-motion` 生效；屏幕震动可关；无 > 3 Hz 闪烁。
- [ ] 图标 license 报告与开源非商业声明齐全；仅使用 CC0-1.0/MIT/Apache-2.0，品牌图标有免责声明与通用回退。

### 风险
- 商标/许可：优先 `mdi/carbon/devicon` 通用图标，品牌图标仅作“软件识别”并记录来源。
- iOS 音频：必须在用户手势内 resume，且处理来电/静音开关。

## 8. M6 · 移动端 / 性能 / 发布

### 范围

- 移动端：**仅横屏**、安全区、手势防误触、旋转提示/暂停、暂停可达、性能降级（动态分辨率）。
- 性能：首屏、FPS、内存、长局稳定性（30 min 不掉帧）。
- 兼容矩阵：Chrome/Edge/Firefox/Safari 17+、iOS 16+、Android 10+。
- 发布：静态托管、版本号、回滚、错误监控（可选、无 PII）。

### 验收
- [ ] 断网后刷新仍可完整游玩（PWA 缓存）。
- [ ] 中端手机 30 min 平均 ≥ 55 FPS，内存峰值 < 120 MB（30 §15.4）。
- [ ] 首访 4G 可操作 ≤ 2.5 s；重复访问 ≤ 1.5 s。
- [ ] 全部浏览器矩阵通过冒烟：横屏开局→双摇杆战斗→暂停→死亡→结算→抽取。
- [ ] 竖屏旋转提示/恢复横屏可继续本局；`autoLock` 默认关闭且可持久化。
- [ ] 发布清单（§10）全绿。

- Safari 的 AudioContext/Canvas 差异：M5 起每周真机回归。
- 缓存更新：Service Worker 版本化，避免用户卡旧版本；提供“刷新以更新”。

## 13. 定义完成（DoD）

一个功能只有同时满足以下条件才算完成：

1. 行为符合对应设计稿，且设计稿无未决冲突。
2. 有自动化测试或明确的手工验收步骤。
3. 桌面与移动端均验证（涉及 UI/输入时）。
4. 不突破体积/性能预算。
5. 文案、稀有度颜色、图标均有最终资源（无占位）。
6. 存档兼容（涉及持久化时）。
7. 更新 `docs` 中受影响的章节或 ADR。
