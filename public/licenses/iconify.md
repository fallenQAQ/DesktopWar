# Icon & asset licenses

DesktopWar MVP uses programmatic, first-letter software tiles (fallback L3 in
`docs/40 §4.5`). No third-party icon set is bundled in this build.

The planned production pipeline uses only CC0-1.0 / MIT / Apache-2.0 icon sets
(`logos`, `simple-icons`, `devicon`, `mdi`, `carbon`) and will generate this
report at build time (`docs/30 §9.7`). Brand names and logos remain trademarks
of their respective owners and are used only for descriptive/parodic desktop
identification; no sponsorship or endorsement is implied.

DesktopWar is an open-source, non-commercial project.
